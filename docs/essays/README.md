# <장부 이후 (After the Ledger)> 고대 문자문화 8대 연구 에세이 모노그래프 집성

본 디렉토리(`docs/essays/`)는 <장부 이후 — 고대 문자문화 비교 연구 아틀라스> 프로젝트의 핵심 연구 성과를 담은 **8대 학술 연구 에세이 전문(Full Monograph Text)**을 수록하고 있습니다.

각 에세이는 21세기 디지털 비문학(CDLI, DCCLT, HMP, eBL, RTI/MSI) 및 비교 문자학 최신 이론에 기초하여, 1차 사료(Grade A) 비문 원문 판독, 3중 표기 체계(원문-전사-직역), 20/21세기 학술 논쟁, 참고문헌을 완비한 정식 학술 논문 형태로 집필되었습니다.
